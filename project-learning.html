CASE STUDY / 01

Learning,
taking flight.

A personal learning website that turns frontend fundamentals into a small, interactive experience.

Visit the live website ↗
FORMAT

Four-page learning website

TOOLS

HTML / CSS / JavaScript

DEPLOYMENT

GitHub Pages

THE GOAL

A place to learn
by doing.

Build a learning website with a photographic homepage, a collection of at least 15 quotes, shared navigation, project ideas, a useless machine, and an interactive game.

What came together

  • A quieter visual design, using whitespace and a clear type hierarchy.
  • A random quote hero that changes without repeating the current quote.
  • Memory matching with three difficulty levels and personal records.
  • A five-round reaction test and a self-switching machine with a soft chime.
  • Responsive pages deployed through an independent GitHub repository.

A useful next step

Continue improving keyboard feedback and collect real feedback on the games and page navigation.
