THE SEED

A place to learn
by making.

The assignment began as a set of separate exercises. I brought them together into one responsive website with a shared visual language and navigation.

What grew

  • A random quotation feature with fifteen entries.
  • A memory game with difficulty levels and best scores.
  • A five-round reaction challenge with timing feedback.
  • A self-switching machine with a soft audio chime.

The project taught me how browser state, events and responsive styling can turn static pages into a connected experience.
