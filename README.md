# Matt / Personal Portfolio

Project 2 — local review scaffold. Separate from the learning website (Project 1).

## Preview
Run `python -m http.server 8001` from this folder, then open http://localhost:8001.
No build tools or dependencies required. Direct file opening also works.

## Structure
- index.html — introduction, selected work, approach, contact entry.
- work.html — filterable work collection; planned ideas are clearly marked.
- project-learning.html — case study for the completed learning website.
- about.html — current learning focus and skills; no invented credentials.
- contact.html — confirmed public GitHub account and learning site links.
- css/style.css — responsive visual system.
- js/site.js — shared navigation/footer and project category filters.
- assets/ — favicon and self-contained preview of the first project.
- screenshots/ — review screenshots.
